HOW TO GET STARTED
==================

1. Local Development
   ─────────────────
   npm install        # Install dependencies
   npm run dev       # Start dev server (auto-running)
   
   Visit: http://localhost:3000
   
   Test the flow:
   • Click "Get Started"
   • Sign up
   • Complete onboarding
   • Chat with Benny
   • View ledger

2. Environment Setup
   ──────────────────
   Required .env variables:
   
   DATABASE_URL=postgresql://...      # Neon PostgreSQL
   OPENAI_API_KEY=sk-proj-...        # OpenAI API key
   COMPOSIO_API_KEY=...              # Composio SDK key
   BETTER_AUTH_SECRET=<random>       # Auth secret
   BETTER_AUTH_URL=http://localhost:3000
   GOOGLE_CLIENT_ID=...              # Google OAuth (optional)
   GOOGLE_CLIENT_SECRET=...          # Google OAuth (optional)

3. Database Setup
   ────────────────
   # Create database schema
   npx prisma migrate dev --name init
   
   # Seed demo data (optional)
   npx prisma db seed

4. Deploy to Vercel
   ─────────────────
   a) Push to GitHub
      git push origin main
   
   b) Import on Vercel
      vercel.com/new → Select repo → Deploy
   
   c) Add environment variables in Vercel settings
      (Same as .env, but use production URLs)
   
   d) Run migrations
      npx prisma migrate deploy
